# cheapshark-explorer
web-приложение с использованием React или аналогичного фреймворка.

Приложение включает следующие компоненты:

- [ ] Приложение должно быть адаптивным и работать на различных устройствах -- как минимум десктоп и телефон.
- [ ] Можно использовать любые библиотеки и инструменты, которые вы считаете необходимыми.
- [ ] Приложение должно быть развернуто на платформе, доступной для проверки (например, GitHub Pages).

Функциональные требования:

- [x] Подключить API Cheapshark (https://apidocs.cheapshark.com/)
- [x] Дать пользователю возможность указать критерии поиска игр: посмотреть что есть в API, подумать как добавить поиск по тегам.
- [x] Дать пользователю возможность просматривать результаты поиска, включая название игры, цену, платформу и ссылку на магазин.
- [x] Дать пользователю возможность сортировать результаты поиска по цене, рейтингу и дате выхода.
- [x] Добавить страницу с аналитикой по текущим скидкам на игры, используя данные из API. На этой странице можно отобразить графики и диаграммы, показывающие тенденции цен на игры. Для рисования графиков можно использовать библиотеки, такие как Chart.js или D3.js.

Нефункциональные требования:

- [ ] Приложение должно быть отзывчивым и быстро загружаться.
- [ ] UI должен быть интуитивно понятным и удобным для пользователя.
